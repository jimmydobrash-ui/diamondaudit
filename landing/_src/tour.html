1 Score

The same rubric in front of every coach.

Every athlete is scored on the same calibrated 0–10 scale, with the rubric right on screen — so one coach's 7 means what the next coach's 7 means.

  • ✓ A calibration ruler shows what each score means as you slide.
  • ✓ Position-aware — catchers get the catching category, others don't.
  • ✓ Number fields for measurables like velo and pop time.
  • ✓ Grade Offer / Bubble / Pass without leaving the screen.
2 Roll up

Every coach's scores become one number.

DiamondAudit averages the skills each coach scored into a single, ranked leaderboard — on one 0–10 scale, the same on every screen — while keeping each coach's view when you need to compare.

  • ✓ Filter by age group, sort by any skill.
  • ✓ Tier labels from the rubric (Elite, Above Avg, Average…).
  • ✓ Export the whole board to CSV in one tap.
3 Decide

Build the roster before you leave the field.

Sort the room into Offer, Bubble, and Pass — every call backed by the scores your staff actually gave, and saved as a record you can point to when a decision gets questioned.

  • ✓ One tap to grade; the summary updates live.
  • ✓ Each grade is stored per coach, per player.
  • ✓ A defensible record behind every cut.
4 At a glance

The whole tryout, the moment you open it.

Players in, evaluations done, average and top scores, and the top of the board — a live read on where the tryout stands without digging.

  • ✓ Stats update as coaches submit.
  • ✓ Top players surfaced automatically.
  • ✓ Jump straight into evaluating or results.

Run the whole tryout from your phone.

Every coach evaluates on the device already in their pocket — no clipboards, no laptop at the table. Scores sync to one shared board in real time.
